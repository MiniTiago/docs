# Kraken: Bun

A runnable public-price example using `@siebly/kraken-api`. No API key is required.

Install Bun first.

## Run

From this folder:

```sh
bun install
bun run start
```

To receive one WebSocket price and close the connection:

```sh
bun run stream
```

[Follow the complete step-by-step guide](https://sieblyio.github.io/docs/kraken/environments/bun.html).
