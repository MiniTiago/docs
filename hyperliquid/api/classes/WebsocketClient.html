ts
subscribe(subscriptions: 
  | WebsocketSubscription

Subscribe to one or more wire topics. Listen for data with on('message'). Topics are cached before connecting and restored automatically after reconnect. The promise confirms local sending; server acknowledgements emit 'response'. Resolve display aliases explicitly with nameToCoin() when needed.
